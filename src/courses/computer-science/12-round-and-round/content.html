Everything computers are feared and admired for comes down to this: they repeat without getting bored.

Every fork in Module 11 sent the lantern down one road, once. Tonight the lantern runs a loop — a circular track it can go round again and again, exactly as many times as the code says. Three keywords each define a different shape of loop: FOR counts a known number of laps, WHILE checks its condition before it boards, and REPEAT checks after — so it always makes at least one lap. Set the dials, tap Step for one lap at a time or Run to let it go, and the station board reports exactly what the loop is doing, lap after lap.

Same deal as always: no marks, no timer, no wrong answers, nothing to hand in. Laps run as many times as you like — nothing about a loop ever runs out or gets marked wrong. Take a nudge whenever you fancy one. Stars can never be taken away.

FOR is for when you already know exactly how many laps you want. FOR Lap ← Start TO End STEP Step runs its body once for every value from Start to End, moving by Step each time, then NEXT Lap closes the loop. Both ends count — FOR 1 TO 5 makes five laps, not four. Set the three dials below, tap Step for one lap at a time or Run to send the lantern round the whole track, and read the station board to see how many laps it actually made.

WHILE condition DO … ENDWHILE tests its condition first, before the body ever runs. If that very first test comes back false, the body never runs — not even once.
