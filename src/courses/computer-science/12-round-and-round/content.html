Everything computers are feared and admired for comes down to this: they repeat without getting bored.

Every fork in Module 11 sent the lantern down one road, once. Tonight the lantern runs a loop — repeating exactly as many times as the code says, not just once. Three keywords each define a different shape of loop: FOR counts a known number of laps round a circular track, WHILE checks its condition before it boards, and REPEAT checks after — so it always makes at least one lap. Each shape gets its own diagram below; tap through at your own pace and watch exactly what the loop is doing, lap after lap.

FOR is for when you already know exactly how many laps you want. FOR Lap ← Start TO End STEP Step runs its body once for every value from Start to End, moving by Step each time, then NEXT Lap closes the loop. Both ends count — FOR 1 TO 5 makes five laps, not four. One line of pseudocode, but three separate things happen each lap — set the three dials below, then tap Step to work through them one at a time: check the bound, run the body, move the counter on — and only once the counter's actually moved does the lantern hop to the next station. Tap Run to let the whole thing play out, and read the station board to see how many laps it actually made.

WHILE condition DO … ENDWHILE tests its condition first, before the body ever runs. If that very first test comes back false, the body never runs — not even once. Below is that idea drawn as a flowchart: the diamond guards the door. WHILE Queue > 0 DO
OUTPUT "Boarding — queue now ", Queue - 1
Queue ← Queue - 1
ENDWHILE

REPEAT … UNTIL condition runs its body first, and only checks the condition afterwards — so the body always runs at least once, even if the very first guess would have matched anyway. Below is that same idea drawn as a flowchart: tap it to send the lantern into INPUT Code, tap a code to feed it a guess, then tap the chart again to check UNTIL Code = "19" — a "no" sends the lantern straight back round to INPUT Code for another try, and only a "yes" lets it carry on to Stop. 19 is one of the four codes on offer, in case you fancy sending yourself through. Notice: even a lucky guess of 19 still has to travel all the way round that loop once before the lantern can reach Stop.
