Time to stop reading the language. Start commanding it.

Last time you learned to read Cambridge's dialect out loud. Tonight you get to run it. Every box you'll ever declare, fill, or print starts with the same three moves — DECLARE makes an empty box, ← drops a value in, OUTPUT prints what's inside. You'll watch it happen live, on boxes you name yourself.

Boxes also come in shapes — whole numbers, decimals, words, single letters — and a value only goes in if it fits. Nothing here ever refuses with an error. A shape that doesn't fit just gets a polite, specific "try something shaped like this instead."

Same deal as always: no marks, no timer, no wrong answers, nothing to hand in. Every box is yours to fill however you like — take a nudge whenever you fancy one. Stars can never be taken away.

Fit every box its own shape…

Try 19 on the INTEGER box — it fits, whole numbers always do. Now try 19 on the REAL box — it fits there too, REAL just doesn't insist on a decimal point. But try 3.75 on the INTEGER box and watch it decline: INTEGER has no decimal place to put the .75.
Read the badge above each box — that's its shape. Pick a value from the tray that matches, then tap the box.
INTEGER only ever takes whole numbers — no decimal point. REAL is more generous: it takes whole numbers and decimals. STRING is text in double quotes; CHAR is exactly one letter in single quotes.

A CONSTANT looks like a box, but it's glued shut the instant it's made — its value is set once, in the same line that declares it, using = rather than ←, and after that nothing can change it. An ordinary box made with DECLARE stays open for business all program long. Watch the difference below.

Notice both halves…

Pi was fixed at 3.14 the moment it was declared. Asking it to become 3.14159 changes nothing — the box is glued shut, and the caption says so warmly rather than complaining. Price, meanwhile, was declared empty, filled with 10, and can be refilled with 12 whenever the program likes — that's the entire difference between the two keywords.
Press both buttons and read the caption each time — one box budges, one doesn't.
CONSTANT Pi = 3.14 sets Pi's value on the spot, for good. DECLARE Price : REAL just reserves the box — Price ← can fill it, and fill it again later, as many times as the program needs.
