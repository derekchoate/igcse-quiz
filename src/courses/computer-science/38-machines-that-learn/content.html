Everything the expert system was taught in Discovery 3 lives in memory — and memory empties the moment the power goes off. Below are six pseudocode lines, shuffled: three that save the new fact to a file, and three that read it straight back. Tap them, one at a time, in the only order that actually works.

Tap the line that has to come first.

The whole sequence, in the only order that works: open the file FOR WRITE, WRITEFILE the new fact into it, CLOSEFILE it — then open the very same file again, this time FOR READ, READFILE the fact back out, and CLOSEFILE it once more. Below, you'd just tap the six tiles in that order; nothing to type.
Nothing can be read from or written to a file until it's been OPENFILEd — and a file can only be open in one mode, READ or WRITE, at a time.
A file opened FOR WRITE has to be CLOSEFILEd before it can ever be reopened FOR READ — the two modes never overlap, and forgetting the CLOSEFILE in between is the single easiest step to miss.
