Switch Arithmetic
✦ 0 stars only ever go up

You can read the language. Now make it do maths.

Every calculator, every game engine, every bank transfer eventually comes down to bulbs added to other bulbs. In the next twenty minutes you'll watch two rows of switches add themselves, discover what happens when a byte runs out of room, learn the sliding trick that doubles or halves a number in one press, and find out how a machine this simple can count backwards below zero.

Same deal as always: no marks, no timer, no wrong answers, nothing to hand in. Flip switches, follow curiosity, take a nudge whenever you like. Stars can never be taken away.

You already know a single switch can say 0 or 1. Here's the bit nobody tells you: switches can add. Light two of them — call them A and B — and watch what their total becomes. Three of the four combinations are painless. The fourth is where things get interesting.

Try every combination…

There are only four ways to set two switches — try all of them, in any order.
When both A and B are lit, the sum bulb can't show "2" on its own — it borrows a second column. Sum shows 0, carry lights: together that's 10, which is how the secret language writes two.

Two full rows of switches, and a sum row underneath that lights itself — you never touch it, it just answers. Set A and B to anything you like. Watch closely when a column has two switches lit at once: the sum bulb there can't hold "2", so it hands the extra off to the column beside it. That handoff is called a carry, and it can ripple for miles.

Make A + B come to…

Add column by column from the right, the same way the sum row is quietly doing it for you.
Find a column where both switches are lit. The sum bulb there can't show "2", so it carries into the column to its left — exactly like the very first discovery, just with more columns to ripple through.

A byte only has eight bulbs, which means it can only count up to 255. Set A and B so their true total climbs past that, and watch the sum row show something smaller than you'd expect — the carry from the last column has nowhere left to go, so it simply vanishes. This is called overflow, and it happens inside real computers more often than you'd think.

What's the biggest number 8 bulbs can hold?
Try 200 + 100 — where would the ninth bulb go?
There is no ninth bulb. The carry is lost: that's overflow.

One board, two new buttons. Shift left and every bulb's value doubles — the whole pattern slides one place up, and whatever was lit in the leftmost bulb falls off the edge for good. Shift right and it halves the same way, losing whatever was in the rightmost bulb. No maths required — just watch the pattern slide.

Along the way, try to…

Shift left is the same as adding a number to itself — doubling. Shift right splits it in half and throws away any leftover; there's no rounding here.
Light the two highest bulbs (192) and shift left once. Where did the missing amount go? There's no room for it — that bulb simply falls off the edge.

Every number so far has been zero or positive. Here's the machine's trick for going below zero: flip every bulb to its opposite, then add one. Set a small positive number, try it, then switch on the sign lens — it relabels the leftmost bulb from +128 to −128, and suddenly the byte can count backwards.

Sign lens on: the leftmost bulb is now worth −128, not 128.

Using flip, add 1 and the lens, reach…

Flip every bulb first — every 1 becomes 0 and every 0 becomes 1. Then add one to whatever that leaves you with.
Try it starting from 1: flipped is 11111110, add one makes 11111111 — every bulb lit. Now switch on the sign lens. What does the leftmost bulb mean now?
With the lens on, the leftmost bulb is worth −128, not 128. All-bulbs-lit reads as −128 + 64 + 32 + 16 + 8 + 4 + 2 + 1, which is −1. It's not a minus sign bolted on — the bulb's own value changed.

Notice what just happened — a third time

Twenty minutes ago "binary maths" probably sounded like a stretch. You've now added two bytes together, watched a carry ripple down a whole row, pushed a byte past its limit and seen the overflow, doubled and halved numbers by sliding bulbs, and made a byte count backwards below zero. That's four separate ideas Cambridge spends whole lessons on.

Whenever you're curious, the next discovery is what happens when those same bulbs stop meaning numbers and start meaning letters. No rush at all — the stars keep.
