# Blueprint Coverage Audit — v1 (sampled)
### Do the catalogues cover what the exams actually ask?

## Method, stated honestly

A full five-year audit is ~60–90 papers across three subjects — beyond one session, and specified below as a Claude Code task. This v1 audits **real papers question-by-question**:

- **Maths:** 0580 Core Paper 1, June 2024 (all 25 questions), plus partial sight of Feb/March 2024 P1. ⚠️ Structural caveat: these predate the 2025 restructure — from 2025, Core Paper 1 is **non-calculator**. Question *genres* remain valid evidence; the calculator context does not.
- **English:** 0500 **2027 specimen Paper 1**, complete — the exact structure he will sit. Highest-value evidence in this audit.
- **CS:** genre-level audit from syllabus and examiner-report knowledge, **not** from a paper examined this session — labelled accordingly; 0478 question genres are highly stable, but this section awaits paper-level verification.

Verdict format: ✅ covered by an existing blueprint/module · 🟡 covered implicitly, needs explicit naming · 🔴 gap — plan amendment required.

### Maths gaps → amendments required
- **M1 · Order of operations.** No module covers it, and it opens real papers. Amend: new discovery-set inside N2 or a short N2.5 — "the agreed reading order" taught as convention-stated (the owner has prior art: his bilingual BODMAS bridge site). Mints an early process blueprint.
- **M2 · Factors, multiples, primes, HCF/LCM.** N1's "tribes" gesture at it; procedures (factor trees, common-factor reasoning) are absent. Amend: extend N1 or add N1.5 "The Anatomy of Numbers"; mints HCF/LCM blueprints.
- **M3 · Symmetry (line + rotational)** as examinable acts, including *drawing* the lines and *stating* the order. Amend: explicit discoveries in G1; tracing-paper convention taught (exam permits it — insider knowledge).
- **M4 · Unit-conversion chains** (km/h→m/s, cm²→m², time). Amend: name it as a process blueprint in N12; the footprints panel already suits it.
- **M5 · Vocabulary blueprints** ("write down the name of…"). Amend: each geometry module's minted entries include the *names* as gaps ("the line from centre to edge = ___"); Revisit stress-tests them. Anti-memorisation handling: names are minted at the moment the object is understood, never as a glossary.
- **M6 · Calculator craft** (Paper 3) — fraction key, powers, standard form entry, bracket discipline. Amend: a short E-room-style module late in the N strand; plus a plan-wide note that **pre-2025 Paper 1s are calculator papers and must be re-skinned accordingly** when used as Bridge material.
- **M7 · "Give a reason" answers** (angle laws by name) — known genre, not in this paper. The G2 law-catcher already has him assemble law statements; amend: those statements are the minted blueprint's rule sentence, and reason-giving is its Paper-direction use.
- **M8 · Critique questions** ("Tina says X. Is she correct? Explain.") — known genre. Amend: a "referee" blueprint (claim → test it with your own working → verdict with the working as evidence); fits W3 and the estimation culture beautifully.

### English gaps → amendments required
- **E1 · Writer's attitude/viewpoint.** R6 builds impressions *of people in the text*; assessing the *writer's own* attitude (tone, stance, bias) is a distinct skill and a named 2027 question. Amend: extend R6 (or split) — "whose feelings are these?" as an explicit discovery (character's vs writer's), minting "the attitude question" into the codebook. His fact-checking instincts (D3's persuasion lab is the maths-side cousin) make this congenial ground.
- **E2 · The persona response (Q4, 20 marks — a quarter of the paper).** Reading a text, then writing *in the voice of a figure from it*, grounded in its details, structured by given bullet prompts. No current module teaches this hybrid. Amend: new module (R9.5, "Borrowed Voices") — mechanics: harvest text details per bullet (R1/R7 machinery), set the register dial to the persona, then Forge rungs on the response; the companion reads rung-4 attempts. Blueprint: bullets → detail-harvest per bullet → voice → respond. One care note: first-person inhabiting of another's feelings is imaginative pretend-play with explicit rules — frame it as *acting from a script the text provides*, which suits a literal thinker better than "imagine you are her".
- **E3 · Writing marks inside the Reading paper** (5 in the summary, 10 in Q4). Amend: plan note that E-strand accuracy and Forge craft are Paper 1 assets too — affects Bridge harvest framing.

## The full audit — Claude Code task spec

One-time job, high value: download all 0478/0580(Core)/0500 question papers + mark schemes, 2020–2025, all series and variants (plus all new-cycle specimens, which outrank old papers wherever structures changed). For every question: extract type, marks, topic ref, command words → map to a blueprint ID from `blueprint-architecture.md` → output `question-audit.json` + a coverage report flagging every unmapped question. Re-run whenever catalogues change. This also produces, for free, the question bank the Bridge's P-stages will draw from — tagged by blueprint, which is exactly how P1 re-skinning wants them. Copyright note: the database stores classifications and references, not question text; actual papers are used privately for tutoring, not republished.

## Bottom line

The architecture survived contact with real papers — nothing failed structurally, and one specimen question (1f i) is our swap machine verbatim. The sampled audit found 5 maths content gaps, 2 significant English gaps (one worth a quarter of Paper 1), and a handful of items needing explicit naming. All are amendable; none require redesign.
